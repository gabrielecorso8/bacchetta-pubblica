Mano sinistra

Premi un pulsante del controller dopo aver aperto questa pagina sul PC.

Stick sinistro → WASD; pulsanti configurabili → Q / Ctrl. La pagina deve restare aperta. Disattiva Steam Input per questo test per evitare doppi input. Se il browser sospende il controller passando al gioco, il watchdog rilascia i tasti: servirà il percorso nativo.
